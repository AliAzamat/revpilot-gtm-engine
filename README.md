RevPilot — AI GTM Workflow Engine

An advanced GTM-engineering build, all TypeScript/Node. You stand up a Salesforce-style CRM sandbox seeded with messy target-account data, then grow a workflow engine around it — a typed job runner with retries and idempotency keys, waterfall enrichment across mock data providers with per-field fallbacks and a data-quality score, dedup and normalization before upsert, and an at-least-once webhook bus. On top sits the AI layer — LLM account-fit triage behind a strict structured-output contract, and personalized first-touch drafts written to the CRM for human review, never auto-sent. You close the way a real GTM engineer would — with a working low-code recipe interpreter, a build-vs-buy decision memo, and runbooks.

## Stack
- TypeScript
- Node.js
- REST APIs
- webhooks
- LLM APIs
- Salesforce-style CRM data model
